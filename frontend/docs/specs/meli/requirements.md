# MeliPage — Requirements

## Escopo

Gestão de contas e produtos Mercado Livre em `/meli`.

## Requisitos

- Deve listar contas conectadas.
- Deve iniciar conexão OAuth com Mercado Livre.
- Deve desconectar conta.
- Deve listar produtos por conta.
- Deve consultar envio por shipment quando disponível.
