# PriceAnalyzePage — Requirements

## Escopo

Geração e visualização de XML para análise de preços.

## Requisitos

- Deve carregar visão rápida com `GET /price-analyze`.
- Deve gerar XML via `POST /price-analyze/generate`.
- Deve baixar XML via `/api/price-analyze/xml`.
- Deve exibir filtros, tabela e estados vazios/loading/erro.
