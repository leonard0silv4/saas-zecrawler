# CatalogPage — Requirements

## Escopo

Catálogo de produtos e dimensões em `/catalog`.

## Requisitos

- Deve listar produtos com busca e cursor.
- Deve criar, editar e excluir produtos.
- Deve importar produtos por XLSX.
- Deve calcular/exibir peso cúbico quando dimensões estiverem disponíveis.
- Deve oferecer verificador de pacote.
