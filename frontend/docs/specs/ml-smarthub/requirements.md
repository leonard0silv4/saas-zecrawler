# ML SmartHub Frontend — Índice legado

Esta pasta foi mantida apenas para compatibilidade com referências antigas.

A documentação frontend agora está quebrada por página/componente em `frontend/docs/specs/`, seguindo o mesmo padrão usado no backend:

- `requirements.md`: o que a tela, componente ou serviço deve fazer.
- `design.md`: como foi implementado e quais arquivos participam.
- `tasks.md`: checklist de manutenção e lacunas conhecidas.

Use `frontend/docs/specs/ml-smarthub-platform/requirements.md` como índice principal.
