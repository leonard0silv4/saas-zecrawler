# TeamPage — Requirements

## Escopo

Gestão de usuários e times em `/team`.

## Requisitos

- Deve ser acessível apenas por owner.
- Deve listar usuários e times.
- Deve criar, editar, excluir usuários.
- Deve alterar senha de subusuário.
- Deve criar, editar, excluir times.
- Deve adicionar/remover membros.
- Deve configurar permissões por usuário e time.
- Deve respeitar limites do plano.
