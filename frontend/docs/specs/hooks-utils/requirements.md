# Hooks e Utilitários — Requirements

## Escopo

Hooks, libs e utilitários usados por múltiplas telas.

## Requisitos

- `useMyStores` deve fornecer lojas próprias.
- `useSmartSuggestions` deve fornecer sugestões inteligentes quando usado.
- `MODULE_LABELS` deve mapear módulos para labels de UI.
- `priceAnalyzeXml` deve interpretar XML de análise de preços.
- `notify` deve padronizar feedback.
