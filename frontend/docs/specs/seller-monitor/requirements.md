# SellerMonitorPage — Requirements

## Escopo

Monitoramento de sellers em `/seller-monitor`.

## Requisitos

- Deve listar, criar, editar e excluir sellers.
- Deve executar scraping manual.
- Deve listar produtos e alertas do seller selecionado.
- Deve marcar alertas como lidos individualmente ou em lote.
- Deve fazer polling para atualizar status de scraping.
- Deve respeitar limite de sellers por plano.
